# Project preferences

- During cleanup, move unnecessary files into a dated subfolder of this project's
  `trash` directory instead of deleting them.
- Preserve filenames and enough folder structure to make restoration straightforward.
- Do not overwrite previously trashed files or empty `trash` unless the user
  explicitly requests permanent deletion.
- Keep working source, references, compiler tools, and configuration unless the
  user includes them in the cleanup request.
